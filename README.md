# REA — Reverse Engineer Anything

This public repository is an unofficial mirror of the open-source REA project. The upstream repository and its maintainers remain the source of truth.

- Official source and releases: [morluto/rea](https://github.com/morluto/rea)
- Official website: [rea.tools](https://rea.tools/)
- Complete source archive: [`rea-main.zip`](rea-main.zip), including the original code, documentation, website, workflows, and license.
- Hosted website: [https://akash120405.github.io/REA/](https://akash120405.github.io/REA/)

## Website

GitHub Actions extracts the source archive, builds the existing static website, checks the generated output, and deploys it to GitHub Pages. The site includes REA documentation, guides, and examples. REA's analysis tools (CLI and MCP server) run locally after installation; GitHub Pages does not run those tools.

## Credentials

No provider API key is included. Configure provider credentials locally, and keep them out of source files and Git history.
